# GeoLink — iPhone (PWA)

GeoLink (прежнее название — «Контроль размотки СП10»). Версия для iPhone — корень репозитория; Android-копия в `android/` не меняется.

Возможности GeoLink: журналы-вкладки (ГФО, ТГО и сколько угодно своих) с листами ID и листами работ, значки для журналов,
листов и меток; фильтр таблиц барабаном по касанию заголовка; отмена записанного пикета (кнопка «↶»); анимация завершения
работы со звуком; метки на карте со значками по темам; слои своих листов на карте с настройкой вида в разворачиваемой строке;
учёт по журналам с ТОП лидеров (кубки) за всё время, месяц, неделю или диапазон; звуки нажатий; режим отладки (правка любого текста).
Свои листы настольная программа пока не показывает: в файле проекта они передаются между телефонами. Метки и заметка хранятся на самом телефоне.

Автономное приложение: работает без интернета и без сервера, все данные лежат в памяти телефона (IndexedDB).
Устанавливается через Safari на экран «Домой». С настольной программой обменивается файлом проекта `.rzm`.

## 1. Выложить на HTTPS
Для GPS и офлайн-режима нужен защищённый адрес (https). Подойдёт любой статический хостинг:
GitHub Pages, Cloudflare Pages, Netlify — достаточно залить содержимое этой папки как есть
(работает и в корне сайта, и в подпапке, например `/razmotka/`).

Перед каждой выкладкой после правок выполните: `python3 tools/build_sw.py` (обновляет список файлов и версию кэша).

## 2. Установить на iPhone
1. Откройте адрес в **Safari**.
2. «Поделиться» → **На экран «Домой»**.
3. Запускайте с иконки. Первый запуск — с интернетом (кэшируются файлы), дальше всё работает офлайн.
4. Когда выложена новая версия, приложение само покажет полоску «Доступна новая версия — Обновить».

## Версия для iPhone: оформление и навигация
С 09.10.2026 у версии для iPhone (корень репозитория) свой вид, у Android (папка `android/`) — прежний.
- **Тёмная тема в духе GitHub Primer** (`css/primer.css`): фон #0D1117, панели #161B22, границы #30363D,
  текст #C9D1D9 / #8B949E, акценты синий, зелёный, оранжевый, фиолетовый, красный. Без размытых теней,
  скругления 6px (чипсы 4px), активный элемент — яркая рамка со свечением, числа — моноширинным шрифтом в чипсах.
  Шрифты Inter и JetBrains Mono лежат в `fonts/` (лицензии SIL OFL рядом), работают без сети.
- **Нижняя панель:** Главная (меню разделов), Карта, Данные, Настройки. «Карты» и «Данных» в меню больше нет.
- **Настройки:** звуки, скорость работы, система координат, правила учёта.
- **Карта:** период, слои, подложки, карта из интернета, GPS — в одной кнопке на карте (значок слоёв).
  «Во весь экран» — карта от края до края, без рамок. Удаление размотки и подмотки — на экране «Данные».
- **Звуки вместо голоса** (`js/sfx.js`, набор [UI SFX](https://uisfx.com), звуки CC0 в `sounds/`):
  вход в зону пикета — щелчок `checkpoint`, «Снять пикет здесь» — `snap`, начало, пауза, продолжение,
  завершение — `start`, `pause`, `play`, `complete`. Стиль «механический» или «минимальный», выключатель —
  «Настройки» → «Звуки». Голосового сопровождения в версии для iPhone нет.

## Android
**Приложение (рекомендуется).** Файл `razmotka-sp10.apk` собирается на GitHub сам при каждом обновлении и лежит
в разделе **Releases** репозитория (выпуск «android-latest»):
`https://github.com/ffiyui/razmotka/releases/latest`. Скачайте его на телефоне и откройте; телефон попросит разрешить
установку из этого источника. Новая версия ставится поверх старой, данные сохраняются.
В приложении GPS работает **в фоне**: при погасшем экране и свёрнутом приложении задание засчитывает пикеты, трек
пишется, голос говорит (в шторке висит уведомление «Определяется положение»). При первом запуске разрешите
местоположение («Всегда» или «Во время использования»), уведомления и, для команд голосом, микрофон.
Если телефон всё же останавливает приложение, отключите для него экономию батареи: Настройки → Приложения →
Размотка СП10 → Батарея → «Без ограничений».

Файл проекта `.rzm` можно открыть прямо из файлового менеджера, почты или мессенджера: «Открыть с помощью» →
«Размотка СП10» — приложение сразу покажет, что в файле. Кнопкой «Выбрать файл» в «Данных» файл проверяется сразу
после выбора.

**Скорость.** На слабых телефонах (и всегда в приложении для Android) включается облегчённый вид: без размытия
«стекла», зерна и анимаций, карта в меньшем разрешении. Переключатель — «Данные» → «Скорость работы».
Точки карты рисуются один раз во внеэкранный слой, а при перетаскивании и масштабе переносится готовая картинка:
десятки тысяч пикетов не тормозят карту.

Как устроено: папка `native/` — оболочка Capacitor (фоновая геолокация, системный синтез и распознавание речи,
сохранение файлов через «Поделиться»), `.github/workflows/android.yml` — сборка. Страница внутри приложения — та же
папка `android/`. Приложение подписывается ключом `native/razmotka.keystore` (пароль в `native/patch_android.py`):
без постоянного ключа новая версия не встала бы поверх старой. Журнал последней сборки — ветка `ci-logs`.

**В браузере.** Копия для Android лежит в папке `android/` и открывается по адресу сайта с `/android/` на конце
(`https://ffiyui.github.io/razmotka/android/`): Chrome → «Установить». В браузере фона нет, как и на iPhone.
Папка `android/` больше не копируется из версии для iPhone: правки для Android вносятся прямо в неё, после них —
`python3 tools/build_android.py` (пересобирает офлайн-кэш). Проверка — `python3 tests/ui_work_android.py`.
На Android команды голосом по умолчанию выключены (микрофон может подавать сигнал при каждом включении) —
включаются галочкой в «Данные» → «Голосовое сопровождение».

## Файлы проекта разных версий
Файл `.rzm` любой версии читается везде: на ПК, iPhone и Android.
- нынешний файл с ПК (база + `journal.json`) и файл с телефона (`journal.json`) — как раньше;
- файл прежней версии программы для ПК (в нём только база `razmotka.db`) телефон читает сам: `engine/sqlite.js`
  разбирает базу SQLite и собирает из неё журнал; номера строк считаются так же, как их считает ПК при обновлении
  базы, поэтому при объединении строки не удваиваются;
- на старых телефонах, где встроенный браузер не умеет распаковывать архивы, файл распаковывается своим кодом
  (`engine/zip.js`), а сохраняется без сжатия — такой файл читает и ПК.
Проверка: `python3 tests/test_legacy.py`.

## 3. Работа по заданиям
1. **Загрузить файл проекта** от начальника отряда: «Данные» → «Файл проекта» → «Проверить файл». Приложение покажет,
   что в файле, и спросит, что загрузить. Пустому телефону предлагается «Заменить проект».
2. **Отметить себя**: вкладка «ID старших» или «ID топографов» → галочка в строке таблицы слева от своей фамилии. После этого в списках заданий видны «мои», а файл проекта называется вашим именем.
3. **Задания** — на листах «Размотка», «Подмотка» и «Разбивка», в раскрывающемся списке «Задания» над таблицей.
   Задание — это строка, по которой работа ещё не проведена. У каждого задания кнопка **«На карте»**.
4. **«На карте»** открывает «Поле» во весь экран и подсвечивает диапазон задания. Если у пикетов задания нет
   координат в SPS (обычное дело для разбивки), место считается: по двум ближайшим известным пикетам той же линии,
   а если линии в SPS нет вовсе — по соседним линиям. Такие пикеты обведены пунктиром, место примерное.
5. **Начать работу**: коснитесь карты или кнопки «Начать разбивку / размотку / подмотку». Включится GPS.
   Пикет засчитывается, когда вы вошли в круг вокруг него: **радиус** меняется ползунком на плашке (3–30 м,
   по умолчанию 10 м) и запоминается. На плашке — сколько пройдено, процент и расстояние до ближайшего пикета.
   Плашку можно спрятать вниз кнопкой ⌄ или движением пальца вниз: останутся название и полоска хода;
   касание возвращает её.
6. **Пауза / Продолжить** — можно прерваться и продолжить в другой точке задания. Ход выполнения сохраняется,
   даже если приложение закрылось (задание вернётся на карту на паузе).
7. **Завершить**: приложение спросит: «Вы прошли от … до …, внести изменения вашего задания в журнал? Да / Нет».
   - **Да** — в журнал записывается фактически пройденное; если шли кусками (с паузами), задание делится на
     диапазоны. Непройденное заданием **не остаётся**. Галочка «Записать задание в исходном виде» записывает
     задание целиком, как было выдано.
   - **Нет** — изменения не вносятся, работа останавливается (задание остаётся на карте, его можно начать заново).
   - **Нахлёст** (только размотка и подмотка): если пройденные пикеты уже лежат на поле (размотка) или с них уже
     подмотано (подмотка), приложение сообщит, сколько таких пикетов и где, и спросит: «С нахлёстом» или
     «Без нахлёста» (тогда эти пикеты в журнал не попадут).
8. **Сохранить файл проекта** и передать начальнику отряда: «Данные» → «Сохранить файл проекта». Файл называется
   по исполнителю: `Дульцев К.А. 08.10.2026 22ч55м.rzm`. Если себя не отметили, имя спрашивается при сохранении.
   Куда сохранить, выбирается в системном меню («Сохранить в Файлы», AirDrop, почта, мессенджер).
   Галочки: треки, лист SPS, контуры DXF, правила; «только задания» с выбором вида работ кладёт в файл лишь
   невыполненные задания.

На компьютере начальник отряда загружает файлы (можно несколько сразу), видит табло «кто сколько выполнил»,
сверяет и нажимает «Размотать», «Подмотать» или «Разбить».

Пока задание идёт или пишется трек, приложение не даёт экрану погаснуть (если телефон это разрешает).

### Снять пикет здесь
Пока задание идёт, на плашке есть кнопка **«Снять пикет здесь»** — когда пикет нельзя поставить на расчётном месте.
Следующий по заданию пикет (сосед последнего снятого по ходу движения; в начале — ближний к вам край задания)
записывается снятым и переносится туда, где вы стоите. Пикеты дальше, место которых было только посчитано
(координат в SPS нет), сдвигаются на столько же: разбивка продолжается от нового места. Пикеты с координатами
из SPS остаются на своих местах. Снятые места запоминаются в телефоне; лист SPS и журнал этим не меняются.

### Голосовое сопровождение «626» (только Android)
«Данные» → «Голосовое сопровождение»: выключатель, выбор голоса, «Слушать команды (микрофон)», «Проверить голос».
- при начале: «Разбивка начата» (размотка, подмотка — так же);
- пикет записан: линия и пикет парами цифр — 5105 и 1497 звучат «пятьдесят один ноль пять, четырнадцать девяносто
  семь»; снят кнопкой или голосом — то же и «готово»;
- при завершении: «Разбивка завершена».

Команды: скажите «626», после ответа «Слушаю» — «снять точку здесь», «пауза», «продолжить» или «завершить»
(можно одной фразой: «626, снять точку здесь»). Команды делают то же, что кнопки; без слова «626» ничего не нажимается.
Мужской русский голос на iPhone — «Юрий»: Настройки → Универсальный доступ → Устный контент → Голоса → Русский.
Если его нет, имеющийся голос звучит ниже. Распознавание речи даёт сам телефон: в приложении, добавленном
на экран «Домой», оно может быть недоступно — тогда откройте адрес в Safari или пользуйтесь кнопками.
В браузере говорит и слушает приложение только пока оно открыто на экране; приложение для Android говорит и в фоне.

## 4. Треки
Кнопка с линией на карте начинает запись пути, повторное нажатие заканчивает и предлагает имя. Треки лежат во
вкладке «Треки»: имя, длина, время; галочка показывает трек на карте; «На карте» переводит к нему. Треки можно
положить в файл проекта.
Трек пишется точно по GPS, без сглаживания, но без мусора: положения с точностью хуже 20 м не пишутся, скачки
быстрее 40 м/с отбрасываются, а стоя на месте точки не добавляются (шаг не меньше 3 м и половины погрешности).
Если приложение закрылось во время записи, при следующем запуске (в течение 12 часов) запись продолжается.

## 5. Ещё на карте
- **Поиск пикетов** — кнопка с лупой: линия, ПП от, ПП до, «+» для следующего диапазона.
- **Слои «Разбито» и «Задания на разбивку»**, контуры DXF (приходят с файлом проекта с компьютера;
  загружать сами файлы DXF можно только в настольной программе).

## 6. Данные и резервные копии
- Данные хранятся только на телефоне. iOS может очистить хранилище сайта, если приложение не открывали долго, — приложение просит постоянное хранилище, но надёжнее другое:
- **Раздел «Координаты и копия данных» → «Сохранить копию»** — делайте после каждой смены. Файл сохраняется через меню «Поделиться» (Файлы, AirDrop, почта). «Загрузить копию» возвращает всё как было.
- Выгрузка отчётов в XLSX/CSV — через то же меню «Файл готов».

## 7. Система координат и GPS
- По умолчанию ГСК-2011, зона Гаусса–Крюгера 10 (EPSG:20910, осевой меридиан 57° в.д.). Меняется в разделе «Координаты»; приходит и с файлом проекта.
- X в листе SPS — восток (~450 000), Y — север (~5 700 000), без номера зоны.
- На карте кнопка «Где я» показывает вас и круг точности; «Следить» ведёт карту за вами, «По курсу» разворачивает карту по направлению движения (по GPS, не по компасу).
- **Калибровка:** встаньте на известный пикет, выберите его и нажмите «Я здесь» — приложение запомнит смещение и применит ко всем следующим определениям. «Сбросить» убирает смещение.
- Сдвиг WGS84 ↔ ГСК-2011 (~0,5 м) не учитывается — для привязки к пикету это несущественно.
- iOS останавливает GPS, когда приложение свёрнуто или экран погашен: во время выполнения задания и записи трека держите приложение открытым.

## 8. Тесты (Chromium, Node)
- `node tests/test_project.mjs` — разбивка, задания, оценка места пикета, файл проекта в движке.
- `python3 tests/xproject.py` — обмен файлом проекта с настольной программой в обе стороны.
- `python3 tests/ui_work.py` — работа в поле от загрузки файла до табло на ПК (эмуляция iPhone, подставной GPS).
- `node tests/xcheck.mjs <dir>` + `tests/xcheck_gen.py` — сверка с Python-версией на случайных сценариях.
- `tests/test_engine_real.mjs`, `tests/test_excel*.mjs` — движок, импорт/экспорт Excel.
- `tests/ui_engine.py`, `ui_touch.py`, `ui_sw.py` — интерфейс в эмуляции iPhone, GPS, офлайн.

## Режим `?remote`
Если добавить к адресу `?remote`, страница работает с настоящим Python-сервером настольной версии (без заданий на карте и треков).
