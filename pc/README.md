# GeoLink для компьютера

Та же GeoLink, что на телефоне: журналы ГФО, ТГО и свои, SPS (R, S и свои страницы), карта со слоями, метки, фото
и описания, учёт с ТОП лидеров, задания, треки, файлы проекта .rzm. Работает без интернета (интернет нужен только для
пароля при первом запуске и для карты-подложки).

## Запуск
Нужен Python 3.8 или новее (python.org, при установке отметьте «Add python.exe to PATH"). Сторонние библиотеки не нужны.

- Windows: двойной щелчок по `start.bat` (если не открывается - `start_debug.bat`, он покажет ошибку);
- любая система: `python geolink.py`.

Программа открывается отдельным окном (Edge, Chrome или Яндекс в режиме приложения). Закрыли окно - программа завершилась.

## Где данные
В папке `data` рядом с программой: `data/kv` - журнал, SPS, настройки, метки, фото; `data/blobs` - картинки подложек;
`data/backups` - копия данных при каждом запуске (хранятся 15 последних). Чтобы перенести программу на другой
компьютер, скопируйте папку целиком вместе с `data`.

## Данные прежней программы для ПК («Контроль размотки»)
Скопируйте файл `data/razmotka.db` из папки прежней программы в папку `data` этой программы и запустите её:
GeoLink сама предложит загрузить журнал, SPS и контуры DXF. Предложение появляется один раз. Другой путь - в прежней
программе сохранить файл проекта (.rzm) и открыть его здесь: «Данные» → «Загрузить файл проекта».

## Только на компьютере
«Данные» → «Контуры из DXF»: файлы DXF, архивы zip и rar или целая папка с контурами полей.

## Обновление
Скачайте папку `pc` из репозитория заново и замените файлы, папку `data` не трогайте.
Для разработчика: после правок версии для iPhone выполните `python3 tools/build_pc.py` (копирует страницу в `pc/web`).
